v0.4.2 – In-app updates and TCP media relay

Calls go through the relay when UDP is blocked, and the app updates
itself.

Added:
- In-app update: the app checks GitHub for a newer release, downloads
  the APK and installs it (Menu → Check for updates).
- TCP media relay: voice and video go through the relay when NAT or a
  VPN blocks UDP.
- A menu on the connection screen: theme, trusted keys, updates.

Fixed:
- The previous connection is closed before a new one starts; a "ghost"
  session used to stay behind.
- The list of online users survives a theme change.
