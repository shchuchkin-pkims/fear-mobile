v0.4.1 – Key exchange, identity verification and video calls

Rooms no longer need a key typed in by hand, peers have identities that
can be checked, and calls get video.

Added:
- Create Room makes a room with a fresh key; Join Room receives the key
  from a member by ECDH key exchange.
- Ed25519 identities with trust on first use, and a screen to manage
  trusted keys.
- Video calls (VP8) with adaptive quality.
- Notifications for messages that arrive in the background.
- Light and dark themes; recent servers for a quick reconnect.

Changed:
- Documentation rewritten in English.

Fixed:
- Messages no longer disappear when a notification is tapped.
- The notification icon shows on every Android version.
- The background connection lasts longer (foreground service).
