v0.3.0 – First Android release

The first release of F.E.A.R. for Android, compatible with the desktop
version 0.3.0.

Added:
- Encrypted voice calls: Opus (48 kHz, mono, 128 kbit/s) over UDP,
  every packet encrypted with AES-256-GCM.
- Encrypted messages and file transfer.
- Calls keep running with the screen off (foreground service).
- One APK for arm64-v8a, armeabi-v7a, x86 and x86_64.

Requires Android 7.0 (API 24) or newer.
