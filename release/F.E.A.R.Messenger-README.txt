====================================
F.E.A.R. Messenger v0.4.2
====================================

ОПИСАНИЕ:
---------
F.E.A.R. (Fully Encrypted Anonymous Routing) — кроссплатформенный мессенджер
с end-to-end шифрованием. Поддерживает зашифрованные текстовые сообщения,
аудио- и видеозвонки, передачу файлов. Полностью совместим с PC версией.

УСТАНОВКА:
----------
1. Скопируйте APK файл на телефон или используйте встроенное обновление (Меню > Check for Updates)
2. Разрешите установку из неизвестных источников в настройках Android
3. Откройте APK файл и следуйте инструкциям установки

ТРЕБОВАНИЯ:
-----------
- Android 7.0 (API 24) или выше
- Разрешения:
  * Микрофон — для аудиозвонков
  * Камера — для видеозвонков
  * Интернет — для передачи данных
  * Foreground Service — для работы в фоне
  * Wake Lock — для поддержания активности во время звонка
  * Уведомления — для фоновых сообщений

ВОЗМОЖНОСТИ:
------------
✓ E2E зашифрованные текстовые сообщения (AES-256-GCM)
✓ ECDH обмен ключами (X25519 + crypto_box) — не нужно передавать ключ вручную
✓ Ed25519 верификация личности (TOFU модель)
✓ Зашифрованные аудиозвонки (Opus, AES-GCM)
✓ Зашифрованные видеозвонки (VP8, AES-GCM)
✓ TCP relay для звонков через сервер (NAT/VPN)
✓ Передача файлов с проверкой CRC32
✓ Обновление из приложения (GitHub releases)
✓ Светлая и тёмная тема
✓ Push-уведомления для фоновых сообщений
✓ Список онлайн-пользователей в комнате

РЕЖИМЫ ПОДКЛЮЧЕНИЯ:
-------------------
1. Create Room — создание комнаты с автогенерацией ключа
2. Connect (пустой ключ) — подключение через ECDH обмен ключами
3. Connect (с ключом) — подключение с известным ключом
4. Host Room — запуск встроенного сервера на устройстве

ИСПОЛЬЗОВАНИЕ:
--------------
1. Запустите приложение
2. Введите адрес сервера, порт, комнату и имя
3. Нажмите Create Room или Connect
4. Отправляйте сообщения, файлы, совершайте звонки
5. Меню (☰) — смена темы, проверка обновлений, управление ключами

ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ:
---------------------------
- Шифрование: AES-256-GCM (12-байтовый nonce, 16-байтовый auth tag)
- Обмен ключами: X25519 (ECDH) + Ed25519 подпись
- Аудио: Opus 48kHz mono, 128 kbps
- Видео: VP8, LOW/MEDIUM/HIGH качество
- KDF: BLAKE2b (ctx "fearaudi" id=1, "fearvide" id=2)
- Протокол: TCP (чат, relay), UDP (прямые звонки)
